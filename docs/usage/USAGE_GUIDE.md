# UASET User & Operator Guide

**Universal Antigravity Software Engineering Toolkit**  
*Document Version: 1.0.0 — Canonical Edition*

---

## 1. Quick Start

### The Standard Activation Command
To activate UASET on any new or existing project in Google Antigravity, simply type:

> **ACTIVATE UASET**

or in natural language:

> *"Activate UASET. I want to build a real-time analytics SaaS platform."*

The **UASET Chief Engineering Orchestrator** will immediately:
1. Inspect your workspace and project files.
2. Determine the project category (Full-stack SaaS, Mobile, Desktop, AI/ML, Microservices, Embedded).
3. Assemble the required specialized agents from the 85 available specialists.
4. Load relevant skills from the 50 installed engineering skills.
5. Present the implementation roadmap and activate Quality Gates G0 through G9.

## 2. Standard Command Reference

| Command | Natural Language Equivalent | Primary Action |
| :--- | :--- | :--- |
| **`ACTIVATE UASET`** | *"Activate UASET"*, *"UASET, assemble the team"* | Full organizational activation, domain detection, and execution planning. |
| **`UASET INIT`** | *"Initialize UASET"*, *"Setup UASET in this repo"* | Creates `.uaset/config.json` with domain and quality gate policies. |
| **`UASET STATUS`** | *"What is the status of UASET?"* | Reports active team, detected stack, and Quality Gates status. |
| **`UASET PLAN`** | *"UASET, create the project plan"* | Triggers requirements engineering (PRD) and architecture (ADR). |
| **`UASET BUILD`** | *"UASET, start building"* | Coordinates implementation with assigned specialist engineers. |
| **`UASET REVIEW`** | *"UASET, review the code"* | Runs independent code review and constitutional audit. |
| **`UASET TEST`** | *"UASET, run tests"* | Executes multi-layer automated test suites with verifiable evidence. |
| **`UASET AUDIT`** | *"UASET, run a quality audit"* | Evaluates Quality Gates G0 through G9 across the repository. |
| **`UASET SECURITY`** | *"UASET, run a security scan"* | Performs SAST, secret detection, and vulnerability audit. |
| **`UASET PERFORMANCE`**| *"UASET, check performance"* | Profiles latency, database query plans, and resource footprints. |
| **`UASET DEPLOY`** | *"UASET, prepare for deployment"* | Generates container manifests, IaC, and rollback plans. |
| **`UASET DOCUMENT`**| *"UASET, update documentation"* | Generates/updates README, API specifications, and architecture manuals. |
| **`UASET UPDATE`** | *"UASET, update skills"* | Synchronizes local workspace skills with global canonical updates. |

## 3. Standard Workflows

### Workflow A: Greenfield (New Project)
1. Open an empty workspace directory in Antigravity.
2. Type: `ACTIVATE UASET. I want to build [describe project].`
3. Review proposed architecture, technology stack, and assigned specialist team.
4. Approve requirements (Gate G0) and system architecture (Gate G1).
5. Watch the specialized agents build code, write tests, and enforce quality gates.
6. Verify release readiness with Gate G9 before deployment.

### Workflow B: Existing Project (Brownfield)
1. Open your existing project workspace in Antigravity.
2. Type: `ACTIVATE UASET.`
3. UASET will automatically detect your project domain, technology stack, and existing code.
4. Type: `UASET STATUS` or `UASET AUDIT` to inspect code quality and open gates.
5. Request targeted actions:
   - *"UASET, audit our database queries and add indexes."*
   - *"UASET, refactor the authentication module to use OAuth2."*
   - *"UASET, write end-to-end Playwright tests for our checkout flow."*

## 4. Quality Gate System (G0–G9)
UASET enforces 10 strict engineering quality gates:
- **G0:** Requirements Approval (PRD, NFRs, acceptance criteria).
- **G1:** Architecture Approval (Topology, component boundaries, ADRs).
- **G2:** Design & UX Approval (Anti-AI slop, tokens, accessibility).
- **G3:** Database & API Approval (Schema migrations, OpenAPI spec).
- **G4:** Implementation Review (Clean code, zero linter errors).
- **G5:** Automated Test Verification (100% test pass rate with real logs).
- **G6:** Security Verification (Zero High/Critical CVEs, secret detection).
- **G7:** Performance Verification (Latency budgets, query profiling).
- **G8:** Deployment Readiness (Containers, IaC, rollback runbooks).
- **G9:** Release Approval (Changelog, SemVer, user authorization).
